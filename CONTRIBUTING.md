# Contributing

Thank you for helping improve WattWraith.

1. Open an issue describing the user-visible problem or proposal.
2. Create a focused branch and include tests for behavior changes.
3. Run Ruff, mypy, pytest with coverage, and the build before opening a pull request.
4. Do not include real household traces, credentials, or data without a clear license.

Contributions are accepted under the MIT License. Please keep detection claims
explainable and avoid inferring personal behavior from power readings.

# Security Policy

## Supported version

Security fixes target the latest tagged release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public
issue containing secrets, private energy traces, or exploit details. Include the
affected version, reproduction steps, and expected impact.

WattWraith is an analysis aid, not a safety controller. It must not automatically cut
power to medical, refrigeration, or other essential devices.
